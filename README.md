## Descripción

Este repositorio contiene el Reporte Técnico correspondiente a la Pre-Entrega 2:
"Mi primer laboratorio seguro de ciberseguridad".

Durante la práctica se configuró un entorno virtual mediante Oracle VirtualBox,
aplicando medidas básicas de seguridad y hardening en Windows y Kali Linux.

## Contenido del laboratorio

- Configuración de red en modo NAT.
- Creación de un usuario estándar en Windows.
- Verificación de Windows Update.
- Actualización de paquetes en Kali Linux.
- Gestión de permisos mediante chmod y ls -l.
- Creación de un snapshot de seguridad.
